# Continuity Tester PCB

A simple 2-layer Continuity Tester PCB designed using KiCad.

## Features
- 2-Layer PCB Design
- Front Copper (F.Cu)
- Back Copper (B.Cu)
- Copper Zone (Ground Plane)
- Gerber Files Generated
- Drill Files Generated
- ERC Passed
- DRC Passed (0 Errors, 0 Warnings)

## Software
- KiCad

## Gerber Files Included
- F_Cu.gbr
- B_Cu.gbr
- F_Mask.gbr
- B_Mask.gbr
- Edge_Cuts.gbr
- PTH.drl
- NPTH.drl

## PCB Features
- Through-hole Components
- Ground Plane
- Test Points
- Speaker/Buzzer Output
- 9V Power Supply
