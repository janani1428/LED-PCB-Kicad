# 🔧 LM317 Diode Tester PCB

A compact and reliable **Diode Tester PCB** designed using **KiCad**. This project uses the **LM317 Voltage Regulator** to provide a stable test voltage for checking the health and polarity of diodes. The circuit offers a simple and low-cost solution for electronics students, hobbyists, and beginners.

---

## 📌 Project Overview

This project helps identify whether a diode is:

- ✅ Healthy (Forward Biased)
- ❌ Faulty (Open Circuit)
- ⚠️ Short Circuit
- 🔄 Reverse Connected

The circuit uses LEDs to indicate the testing result, making diode verification quick and easy.
