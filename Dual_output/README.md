🔌 Dual-Output DC-DC Buck Converter

A custom PCB designed to convert a 12V DC input into regulated 5V and 3.3V outputs for embedded-system applications.

⚡ Features

- LM2596-5.0 → 5V Output
- LM2596 Adjustable → 3.3V Output
- Independent 5V & 3.3V switches
- LED power indicators
- Potentiometer for 3.3V adjustment
- Input/output filtering capacitors
- Dedicated pin headers

🛠️ Tools

- KiCad
- Schematic Design
- PCB Layout & Routing
- DRC Verification

🎯 Applications

Designed for Arduino-, ESP32-, sensor-, and IoT-based projects requiring 5V and 3.3V power rails.
