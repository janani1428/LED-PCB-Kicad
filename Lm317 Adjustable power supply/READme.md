# ⚡ LM317 Adjustable Power Supply PCB

A custom-designed **LM317 Adjustable Power Supply PCB** developed using **KiCad 9**. This project converts an AC input through a bridge rectifier and provides an adjustable regulated DC output using the LM317 voltage regulator.

## 📌 Project Overview

This project was designed to understand the complete PCB design workflow, including:

- Requirements Analysis
- Schematic Design
- Component Selection
- Datasheet Study
- PCB Layout
- Copper Pour
- 3D PCB Verification
- ERC & DRC Validation
- Gerber File Generation

---

## ✨ Features

- Adjustable DC Output using LM317
- Bridge Rectifier (1N4007)
- Filter Capacitors
- Through-Hole Components
- Compact PCB Layout
- Easy Assembly
- Beginner-Friendly Hardware Design

---

## 🛠 Components Used

| Component | Description |
|-----------|-------------|
| LM317T | Adjustable Voltage Regulator |
| 1N4007 | Rectifier & Protection Diodes |
| Electrolytic Capacitors | Input & Output Filtering |
| Fixed Resistors | Voltage Divider |
| Potentiometer | Output Voltage Adjustment |
| Input Connector | AC Input |
| Output Connector | Adjustable DC Output |
