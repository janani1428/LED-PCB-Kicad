# 💧 Water Level Indicator – PCB Design

A transistor-based Water Level Indicator circuit designed using KiCad.

## 📌 Project Overview

This project focuses on the schematic and PCB design of a
Water Level Indicator circuit using BC547 transistors,
LED indicators, and a buzzer.

The design provides indication for different water levels:
25%, 60%, 75%, and 100%.

## 🔧 Design Features

- 25% Water Level Indication
- 60% Water Level Indication
- 75% Water Level Indication
- 100% / High-Level Alert
- LED Indicators
- Buzzer Alert
- 9V Battery Supply
- BC547 Transistor-Based Design
